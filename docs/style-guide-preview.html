Section 04

Motion

Tap any button below. The bounce is gsap.to(el, {scale: 1.1, duration: 1, ease: "elastic.out(2, 0.6)"}) — same eases Maxima Therapy uses, same we'll ship.

Add event
Mark done
Give star
Shopping list

Try holding and releasing — the elastic overshoot is what makes it feel alive. On the real touchscreen we'll also emit a tiny haptic (if the Pi supports it on the Acer).
