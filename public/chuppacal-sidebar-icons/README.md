# ChuppaCal sidebar icons

Five Phosphor duotone SVGs recolored to ChuppaCal’s palette. The included `preview.png` shows the complete set.

**Prepared assets only:** these icons have not been integrated into or deployed with an app.

## Icon mapping and original sources

| Local file | Navigation label | Original source | Accent |
| --- | --- | --- | --- |
| `calendar.svg` | Calendar | [calendar-dots-duotone.svg](https://raw.githubusercontent.com/phosphor-icons/core/main/assets/duotone/calendar-dots-duotone.svg) | Sky `#2668FD` |
| `tasks.svg` | Tasks | [check-square-duotone.svg](https://raw.githubusercontent.com/phosphor-icons/core/main/assets/duotone/check-square-duotone.svg) | Clover `#00B351` |
| `lists.svg` | Lists | [notebook-duotone.svg](https://raw.githubusercontent.com/phosphor-icons/core/main/assets/duotone/notebook-duotone.svg) | Sun `#FDCB40` |
| `meals.svg` | Meals | [bowl-food-duotone.svg](https://raw.githubusercontent.com/phosphor-icons/core/main/assets/duotone/bowl-food-duotone.svg) | Coral `#FD4401` |
| `settings.svg` | Settings | [gear-six-duotone.svg](https://raw.githubusercontent.com/phosphor-icons/core/main/assets/duotone/gear-six-duotone.svg) | Petal `#F780D4` |

## Modifications

- Changed the default outline/detail fill to Ink `#1C1A14`.
- Changed the first, background path to the category accent color at full opacity (`1`, originally `0.2`).
- Preserved both original path geometries and the `0 0 256 256` view box.
- Renamed the files to match their intended navigation labels.

The SVGs contain no scripts, external images, fonts, or runtime downloads. The preview uses Beige `#F3EFE0` and Cream `#FAF6E8`; these backgrounds are not baked into the individual SVGs.
